## About Me
Hi, I’m a developer with a strong passion for Linux and web development. I enjoy keeping things simple and focused. When working on something, I like to tackle the core functionality first, then refine the details carefully. That’s one of the reasons I enjoy working with Linux and programming languages like TypeScript, Java, and Go—they align well with my mindset.

Over the past few years, I’ve had the opportunity to work on various web and mobile development projects across different companies. Some highlights include:
- Building RESTful APIs with user authentication and management.
- Designing clean and readable dashboards for data visualization.
- Developing JavaScript-based mobile apps that work seamlessly with multiple microservices.
- Implementing repository and singleton design pattern in my projects.

Outside of work, I spend time playing games, reading tech articles, watching Netflix with a cup of green tea, and—of course—writing code.
